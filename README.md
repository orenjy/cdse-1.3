2. [프로젝트 2] 자유 주제 자동화 설계 및 구현
   - 자동화할 반복 업무 1개 정의
      - 새로 올라온 뉴스 중 ai or 인공지능이라는 단어가 제목에 있는 뉴스를 노션에 저장하기
   - 자동화 도구 1개 선정 및 선정 이유 작성
      - make 선택
      - 이유는 과제에서 추천했기 때문, 강의가 다른 도구에 비해 잘 다루어져 있기 때문, 초보자 자동화 툴로 추천되고 있기 때문이다.
   - 워크플로우 설계 문서 (설명 또는 다이어그램 포함)
      - 위에서 써서 더 추가할 필요 없을거 같음
   - 구현 화면 캡처
      - 위에 있음
   - 실행 결과 화면 캡처
      - 위에 있음

- 보너스 과제
   - make를 gpt와 연결해 요약 기능을 추가하였음
 
- 민감 정보 보호
   - api키만을 사용하였는데 이것도 플랫폼 자체 지원을 사용한거라 키가 텍스트로 적혀있지 않음

- 입력/핵심 액션/분기/최종출력의 매핑
   - 입력 : 일정시간이 되거나 작동 버튼을 누름
   - 핵심 액션 : 구글에 기사를 검색해서 하나를 가져옴
   - 분기 : 제목안에 ai가 있으면 실행 (지금은 정하고 싶은 조건이 없어 통과하기 쉬운 필터를 걸었지만. 조건 변경 쉽게 가능. 제목에 '미국'이 있으면 실행하지 않는다 식의 필터로 변경 가능)
   - 핵심 액션2 : openAI를 이용해 기사를 요약함
   - 최종출력 : 노션에 요약된 기사와 url, 날짜가 저장됨

- 모니터링 방법
   - 도구 안에 기본적인 로그가 있고, 실행 할 때 어느 노드를 지나고 있는지 시각적으로 표현해줘서 모니터링이 가능하다고 생각함

- 자동화가 복잡하게 어떻게 처리할 것인가
   - 모듈화를 통해 함수 호출을 하듯이 나눠서 사용하는 식으로 하면 동일한 모듈을 다른 기능을 이용할 때 사용할 수 있어 조금 더 효율적일 것이다.

- 노코드의 한계와 기반 확장 방법
   - 코딩을 배우는게 가장 확실하지만 안된다고 가정했을 때 좋은 방법은 노코드로에서 안되서 추가해야되는 기능을 바이브 코딩으로 해야하는 것일거 같다.
